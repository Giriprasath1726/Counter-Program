# Counter Program 🧮

A simple and elegant web-based counter application built with **HTML**, **CSS**, and **JavaScript**. Users can increase, decrease, or reset the counter with a single click. Ideal for beginners learning DOM manipulation and interactive UI design.

## 🔧 Features

- ✅ Increment the counter
- ✅ Decrement the counter
- ✅ Reset the counter to zero
- ✅ Smooth hover and active button effects
- ✅ Clean, responsive UI using modern design
